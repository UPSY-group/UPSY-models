Welcome to the Utrecht Polar SYstem models repo!

**UPSY** is a geoscientific modelling toolkit, containing modules for unstructured mesh generation, discretisation, remapping, and i/o. The UPSY-models repo also contains the UFEMISM ice-sheet model and the LADDIE sub-shelf melt model, both of which are built on UPSY.

Take a look at the UPSY-wiki [Getting started](https://github.com/UPSY-group/UPSY-models/wiki/Getting-started) page to learn how to get your UPSY model up and running.

UPSY's [GitHub Pages](https://upsy-group.github.io/UPSY-models/) show output for common benchmark experiments using the latest model version.
